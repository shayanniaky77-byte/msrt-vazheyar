واژه‌یار MSRT — نسخه کروم با دکمه نصب و اجرای آفلاین

توجه مهم:
Chrome اجازه نمی‌دهد یک فایل HTML که در Downloads قرار دارد به صورت خودکار و با یک کلیک به یک برنامه نصب‌شده تبدیل شود.
دکمه «نصب روی گوشی» فقط وقتی پنجره نصب Chrome را نشان می‌دهد که برنامه از HTTPS معتبر باز شده باشد، مرورگر شرایط نصب را احراز کرده باشد و کاربر نصب را تأیید کند.

روش نصب صحیح، فقط یک‌بار با اینترنت:
۱) محتوای این بسته را (فایل‌های index.html، sw.js، manifest.webmanifest و دو آیکون) روی یک هاست HTTPS عمومی بدون رمز بارگذاری کنید؛ مثلا GitHub Pages یا Cloudflare Pages. فایل‌ها باید کنار هم در یک پوشه باشند.
۲) آدرس دقیق index.html را در Google Chrome روی اندروید باز کنید.
۳) صبر کنید تا نشان «فایل‌ها برای آفلاین آماده‌اند» در صفحه اصلی دیده شود.
۴) «نصب روی گوشی» را لمس و درخواست Chrome را تأیید کنید. اگر پنجره نصب ظاهر نشد، از منوی ⋮ Chrome گزینه Install app یا Add to Home screen را انتخاب کنید.
۵) برای اطمینان، حالت هواپیما را روشن کنید و از روی آیکون برنامه آن را باز کنید. بعد از نصب صحیح، برای بازکردن برنامه به اینترنت، Netlify و رمز ورود نیاز نیست.

فایل MSRT_Chrome_Local_Offline.html:
این فایل حتی بدون هاست و اینترنت با مرورگر دارای دسترسی به فایل محلی باز می‌شود، اما Chrome نصب اتوماتیک و شورت‌کات آفلاین قابل اتکای PWA را برای فایل:// پشتیبانی نمی‌کند. بنابراین استفاده از این فایل جای نصب PWA نیست.

ذخیره‌سازی:
اطلاعات در حافظه اختصاص‌یافته توسط Chrome به همان origin (آدرس سایت) با localStorage ذخیره می‌شوند و بعد از خروج و ورود باقی می‌مانند. پاک‌کردن داده‌های سایت، حذف برنامه، پاک‌سازی حافظه Chrome و تعویض دامنه می‌تواند داده‌ها را حذف کند. از قسمت تنظیمات، پشتیبان JSON بگیرید و آن را خارج از برنامه نگه دارید.
نمرات مربوط به نسخه قبلی با فایل پشتیبان JSON قابل واردکردن‌اند.

نکته: PWA به موتور Chrome اجرا می‌شود؛ وقتی نصب شد معمولاً در پنجره مستقل بدون نوار آدرس باز می‌شود، ولی همچنان Chrome/WebView را برای اجرا به‌کار می‌برد.
